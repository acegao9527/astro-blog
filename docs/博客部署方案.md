# 博客部署方案

## 整体架构

配套设计图见 [博客架构设计图](./博客架构设计图.png)。

```text
┌─────────────────────────────────────────────────────────────────┐
│                    数据源 (无 Git 的 Oasis/Blog)              │
│  BLOG_SOURCE=directory；BLOG_DIR=../oasis/Blog             │
│  └── YYYY/正式文章 + index.md；其他目录不参与构建          │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    同步脚本 (本地)                               │
│                                                                 │
│   npm run sync:posts                                            │
│                                                                 │
│   scripts/sync-posts.mjs                                        │
│   - 只读 Blog 下的年份目录 和 index.md             │
│   - 规范化 frontmatter                                          │
│   - 自动生成 description                                        │
│   - 复制文章素材到 public/uploads/posts                         │
│   - 写入 .cache/content/posts                                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Astro 静态构建                                │
│                                                                 │
│   npm run build                                                 │
│                                                                 │
│   src/content.config.ts                                         │
│   - 定义 posts collection schema                               │
│                                                                 │
│   src/pages/                                                    │
│   - index.astro                                                 │
│   - post/[slug].astro                                           │
│   - archive/index.astro                                         │
│   - tags/index.astro                                            │

│   - rss.xml.js                                                  │
│                                                                 │
```

## 关键点

### 内容系统

- 写作内容唯一来源为 Oasis/Blog，设置 `BLOG_SOURCE=directory` 和 `BLOG_DIR=../oasis/Blog`
- 设置 `BLOG_SOURCE=directory` 时强制使用 `BLOG_DIR`，即使 `.env` 中存在 `BLOG_REPO_URL`
- Oasis 不执行 Git；站点代码仍在独立 Astro Git 项目维护
- 构建前同步到 `.cache/content/posts`
- 内容同步只扫描 `Blog/` 中的四位年份目录，并单独读取 `Blog/index.md`；其他目录不进入构建
- 文章素材构建前同步到 `public/uploads/posts`
- Astro collection schema 负责字段校验
- 页面渲染使用 Astro 原生 Markdown，而不是手写 `set:html`

### 页面能力

- 首页：最近文章 + 热门标签
- 文章页：SEO、标签、上一篇 / 下一篇
- 归档页：按年份聚合
- 标签页：标签总览与标签详情
- RSS：`/rss.xml`
- Sitemap：由 `@astrojs/sitemap` 生成

### 环境变量

- `BLOG_REPO_URL`：退役仓库恢复参数；当前常规构建不使用
- `BLOG_REPO_REF`：仅用于历史仓库恢复
- `BLOG_SOURCE`：当前必须使用 `directory`，避免读取退役 Blog 仓库
- `BLOG_DIR`：Oasis/Blog 内容目录，相对于 Astro 根解析
- `SITE_URL`：设置站点绝对地址，用于 canonical、RSS 和 sitemap
- 内容源和 `SITE_URL` 都可以写在仓库根目录 `.env` 中，缺失时构建会直接失败
